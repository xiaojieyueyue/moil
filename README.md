# MCU 蓝牙助手

Android 应用项目，提供 BLE 与经典蓝牙设备的双模通信能力，并允许用户通过可视化仪表盘搭建针对单片机的自定义控制界面。主要特性包括：

- **设备管理**：扫描、连接 BLE/经典蓝牙设备，查看配对状态并管理连接。
- **自定义仪表盘**：通过拖拽式组件（按钮、开关、滑块、文本输入、数据标签、仪表、摇杆等）构建控制页面，支持字符串与 HEX 指令配置。
- **串口终端**：实时查看蓝牙串口数据，可切换文本/HEX 显示，并发送临时命令。
- **配置持久化**：仪表盘布局与组件配置自动保存，下次启动自动加载。

## 工程结构

```
app/
├── src/main/java/com/example/bluetoothconsole
│   ├── BluetoothConsoleApplication.kt   // 应用入口 & 依赖注入容器
│   ├── MainActivity.kt                  // UI 入口，注入 ViewModel
│   ├── data/                            // 蓝牙与仪表盘数据层实现
│   ├── model/                           // 仪表盘、终端等数据模型
│   ├── ui/                              // Compose UI、导航与页面
│   └── util/                            // 指令编码等工具
└── src/main/res                         // 资源文件
```

## 构建与运行

推荐使用 Android Studio Iguana (或更高版本) 导入项目并运行。若本地已安装 Gradle，可在项目根目录执行：

```bash
./gradlew assembleDebug
```

> **提示**：仓库内的 `gradlew` 脚本会直接调用系统已安装的 `gradle` 命令，不会自动下载 Gradle 发行版。如果未安装 Gradle，请通过 Android Studio 进行构建。

## 蓝牙权限说明

应用在 `AndroidManifest.xml` 中声明了 BLE 与经典蓝牙扫描/连接相关权限，同时默认请求定位权限以支持 BLE 扫描。在运行时需根据 Android 系统版本提示授予。

## 仪表盘组件说明

- **按钮**：支持配置按下/松开两种指令。
- **开关**：配置开/关指令。
- **滑块**：配置最小值、最大值，可选择以文本或 HEX（单字节）发送。
- **文本输入**：自定义文本并发送。
- **数据标签**：根据可选的前缀过滤显示最新的传入数据。
- **仪表**：根据数值范围展示进度条，支持前缀过滤。
- **摇杆**：输出 -100~100 的 X/Y 坐标，可选择连续发送或仅松开时发送，并支持 HEX/文本模式。

所有组件配置都会持久化到本地 DataStore，方便长期使用。

## 终端功能

串口终端提供实时滚动日志，可在文本与 HEX 显示之间切换。发送区域支持文本或 HEX 输入（HEX 输入需为偶数长度、可包含空格/0x 前缀）。
